# Světlen Tabletop — stažení

Virtuální stůl pro hry na hrdiny (česky).

**Stáhni nejnovější verzi:** [Releases → Latest](https://github.com/arielistelosbutch/svetlen-releases/releases/latest)

- `Svetlen_X_vypravec.zip` — program pro vypravěče (GM)
- `Svetlen_X_hrac.zip` — program pro hráče

Rozbal a spusť `.exe`. Další verze se už stáhnou samy: program je při spuštění najde a v hlavním menu nabídne **Aktualizovat**.
